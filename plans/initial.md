# Game 

## Duck hunt

- Shooting ducks until time expires
- Each duck adds extra time to the timer
- Each duck stays on screen for fixed time
- Each duck changes direction in intervals until it leaves the screen
- Each duck awards points depending on how quickly you shoot it
- Each duck starts from a point in screen at the lowest quarter when split horizontally
- A miss on a duck subtracts some seconds from the timer
- Bigger and lower hitbox for ducks to indicate distance on screen.
- More points for hitting lower hitbox targets.
- Info about the round (timer, points, lives) should be on the bottom of the screen where the ducks cant go.
